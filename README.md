# 🎓 Student Report Management System

A console-based **Student Report Management System** implemented in **C**, designed to efficiently manage academic records using **file handling** and **role-based authentication**.  
The system supports adding, updating, searching, displaying, and deleting student records with proper input validation.

---

## 🚀 Features

### 🔐 Role-Based Login System
- **Admin:** Full access (Add, Display, Search, Update, Delete)
- **Staff:** Search student details
- **User:** View all student records
- **Guest:** Limited viewing access

### 📚 Student Management
- Add new student records  
- Update existing details  
- Delete student entries  
- Search by Roll Number  
- Display all records  

### 💾 File Handling
All data is saved in:
- `student.txt`
- `credentials.txt`

### 🛡 Input Validation
- Accepts only alphabets for names  
- Alphanumeric for roll numbers  
- Digits (including float values) for marks
